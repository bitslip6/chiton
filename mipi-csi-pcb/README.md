# mipi-csi-pcb
 # MIPI-CSI interface for Variscite EVK
 
 * Edge connector on the front, ZIF connector on the back
 * For edge connector, should use CSI_P1. CSI_P2 is not exposed for i.MX8M Mini SOM.
 * Passing MIPI Data0, Data1, CK and I2C signals.
